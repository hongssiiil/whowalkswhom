# Who Walks Whom? / 누가 누구를 산책시키는가?

AI와 함께 그래프를 만드는 과정을 강아지와의 산책에 빗댄 짧은 웹 게임입니다. AI의 제안을 따르는 행동보다 **왜 그 선택을 했는지**에 주목합니다.

## 실행과 플레이

`dist/index.html`을 브라우저에서 열거나 정적 웹 서버의 루트로 `dist/`를 제공합니다. 별도 설치, 계정, API 키가 필요하지 않습니다.

1. AI 채팅 화면의 질문 세 개 중 하나를 고릅니다.
2. `START WALK`를 누르고 WASD 또는 방향키로 이동합니다.
3. 다섯 갈림길마다 번호가 붙은 세 가지 분석 계획 중 하나로 걸어갑니다. AI가 추천하는 계획은 매번 하나입니다.
4. 길을 지난 뒤 그 선택의 이유를 고릅니다.
5. 마지막 깃발에 도착하면 실제 이동 경로와 선택 기록을 봅니다.

각 갈림길의 세 계획은 채팅 답변처럼 산책 화면 아래에서 올라옵니다. 걷기 시작하면 카드가 사라지고 같은 계획이 왼쪽 나침반에 남습니다.

강아지는 스스로 AI 추천 길 쪽으로 당깁니다. 추천 길에서는 눈에 띄게 빨라지고, 다른 계획으로 가려면 붉어진 강아지와 목줄의 저항 때문에 느려집니다. 선택 뒤에는 강아지의 부정적인 반응도 표시됩니다. 게임에는 정답이나 점수가 없습니다. 결말의 그래프는 통계 분석 결과가 아니라 플레이어의 이동 흔적입니다.

## 세 주제와 다섯 결정

시작 질문은 연령과 삶의 만족도, 소득과 행복, SNS 사용 시간과 외로움입니다. 각 주제에는 변수 범위, 변수 묶기, 결측값 처리, 추세와 집단 차이, 결과 해석의 다섯 갈림길이 있습니다. 첫 갈림길은 `성별·연령·교육 수준 모두 / 성별·연령만 / 연령만`처럼 ChatGPT의 계획 선택 형식을 은유합니다. 이후 갈림길에서도 구체적인 세 계획 중 하나를 고릅니다.

## 제작 배경

사회학 수업의 R 통계 실습에서 AI의 도움으로 그래프를 완성하면서, 분석과 시각화의 방향도 AI가 제시한 경로를 따라 선택하고 있다는 의문에서 출발했습니다. AI가 옳거나 그르다는 결론 대신, 제안을 받아들이고 거부하고 목표를 바꾸는 판단을 스스로 할 수 있는지 묻습니다.

## AI 협업과 실패 기록

이 MVP는 AI와 함께 기획과 코드를 작성했습니다. 최초 기획에서는 갈림길을 세 번으로 정리했으나, 실제 의도는 **여러 번의 갈림길마다 세 방향을 선택하는 것**이어서 다섯 번의 삼거리로 수정했습니다. 시작 질문도 한 개로 제한하려던 안에서 세 질문 모두 완주할 수 있는 구성으로 바뀌었습니다. 이후 추상적인 목표 수정 길을 구체적인 분석 계획 셋으로 바꿨습니다.

실제 R 실행과 AI API는 구현하지 않았습니다. 처음 떠올린 ‘데이터 분석 결과처럼 읽는 마지막 그래프’는 근거 없는 수치 해석으로 오해될 수 있어, 경로가 **선택의 은유**라는 안내를 명확히 넣었습니다. 모바일 터치 조작과 자유 입력도 1주 MVP의 핵심 경험인 키보드 이동과 선택 기록을 먼저 완성하기 위해 후속 과제로 남겼습니다.

향후 실제 플레이 테스트에서 목줄 저항이 지나치게 답답한지, 세 분석 계획의 차이가 충분히 전달되는지 확인해 조정할 예정입니다. 이 문서는 구현하지 않은 실패 사례를 꾸며 기록하지 않습니다.

## 발표용 3분 흐름

1. **경험:** AI와 R로 그래프를 완성했지만, 대부분의 방법을 AI가 추천한 대로 고른 자신을 발견했습니다.
2. **질문:** AI와 협업하면서 어떻게 판단의 주체로 남을 수 있을까요?
3. **시연:** 질문을 고르고, 강아지와 함께 세 방향의 갈림길을 지나며 선택 이유를 남깁니다.
4. **결과:** 걸어온 길이 그래프가 되고 다섯 결정의 기록이 보입니다.
5. **마지막 질문:** 그래프는 완성되었습니다. 그 과정의 결정들도 당신의 것이었나요?

## 기술

HTML, CSS, JavaScript, Canvas로 만든 정적 웹 게임입니다. 기록은 한 판 동안 브라우저 메모리에만 남으며 서버로 전송되지 않습니다.
