# Who Walks Whom? / 누가 누구를 산책시키는가?

## 작품명

**Who Walks Whom? — 누가 누구를 산책시키는가?**는 AI와 함께 그래프를 만드는 과정을 강아지 산책으로 바꾼 짧은 웹 게임입니다. 플레이어는 질문을 고르고 다섯 번의 갈림길에서 분석 계획을 선택합니다. AI 강아지는 매번 한 계획을 추천하고 그쪽으로 목줄을 당깁니다. 마지막에는 내가 실제로 걸은 길과 선택 이유를 돌아봅니다.

## 질문 1문장

**AI와 함께 분석할 때, 나는 제안을 검토하며 방향을 정하고 있을까, 아니면 AI가 끄는 대로 따라가고 있을까?**

## 질문과 조사

이 작품은 AI가 옳은지 틀린지를 판정하기보다, AI의 제안 앞에서 사람이 어떻게 판단하는지 살펴봅니다. 시작할 때 연령과 삶의 만족도, 소득과 행복, SNS 사용 시간과 외로움 중 하나를 고르고, 다섯 갈림길에서 변수 범위, 변수 묶기, 결측값 처리, 추세와 집단 차이, 결과 해석에 관한 세 가지 계획 중 하나를 택합니다.

예를 들어 첫 갈림길에서는 `성별·연령·교육 수준 모두`, `성별·연령만`, `연령만`을 비교합니다. 추천을 따르는지, 다른 계획을 고르는지, 그 이유는 무엇인지가 한 판의 선택 기록으로 남습니다. 결말의 그래프는 통계 결과가 아니라 플레이어가 이동한 흔적입니다. 실제 설문이나 R 분석은 수행하지 않으며, 게임 기록도 브라우저 밖으로 전송하지 않습니다.

## AI 활용 과정 (AI USE NOTE)

초기 아이디어와 제작 계획을 바탕으로 AI와 화면 흐름, 주제별 갈림길, 강아지의 행동과 피드백을 구체화하고 웹앱 코드를 만들었습니다. AI가 만든 초안은 그대로 확정하지 않고, 플레이 의도를 설명하며 여러 차례 수정했습니다.

처음에는 갈림길 세 번으로 정리됐지만, 실제 의도는 여러 번의 갈림길마다 세 방향을 고르는 구조였습니다. 이를 다섯 갈림길로 바꾸고, 세 주제가 각각 끝까지 플레이되도록 구성했습니다. 이후 `목표 수정`처럼 추상적인 선택지를 변수 범위를 직접 비교하는 분석 계획으로 바꿨습니다. 시작 화면과 갈림길 카드도 대화형 화면에 가깝게 조정했습니다.

AI는 기획과 구현을 돕는 도구로 사용했습니다. 선택의 의미와 작품의 최종 방향은 제작자가 결정했습니다. 실제 AI API를 연결하지 않아 게임 속 추천 문구는 미리 작성한 시나리오이며, AI가 플레이어의 선택을 실시간 분석하지 않습니다.

## 실패와 배운 점

첫 계획에서는 갈림길 수와 의미를 잘못 단순화해, 원하는 경험과 다른 `AI 추천 / 원래 목표 / 목표 수정` 구조가 나왔습니다. 사용자가 생각한 선택은 목표를 바꾸는 세 갈래가 아니라, 매번 구체적인 분석 계획 세 가지를 비교하는 것이었습니다. 계획을 다시 쓰며 각 선택이 이후 경로와 마지막 기록에 이어져야 한다는 점을 배웠습니다.

또한 목줄의 저항을 강하게 표현하는 과정에서 AI 추천을 향해 걷거나 마지막 목적지로 이동할 때도 강아지가 붉어지는 문제가 있었습니다. 화난 표정은 산책을 거부하는 행동과도 맞지 않았습니다. 이제 다른 방향으로 가려 하면 강아지가 멈춰 서고, 잠시 뒤 바닥에 누워 버팁니다. 사람은 잠깐 멈췄다가 느리게 움직이고, 목줄이 길어지면 누운 강아지가 조금씩 끌려옵니다. 추천 방향으로 돌아오거나 마지막 구간에 들어가면 강아지가 다시 걷습니다. 피드백의 표정뿐 아니라 움직임과 발생 조건을 함께 설계해야 한다는 점을 배웠습니다.

이 MVP는 키보드를 사용하는 데스크톱 브라우저를 기준으로 만들었습니다. 모바일 터치 조작, 자유 입력, 실제 R 실행과 AI 연결은 구현 범위에 포함하지 않았습니다. 후속 플레이 테스트에서는 목줄 저항의 강도와 계획 간 차이가 잘 전달되는지 살펴볼 예정입니다.

## 실행과 플레이

`dist/index.html`을 브라우저에서 열거나 정적 웹 서버에서 `dist/`를 제공합니다. 별도 설치나 API 키는 필요하지 않습니다.

1. 시작 화면의 질문 세 개 중 하나를 선택합니다.
2. `산책 시작`을 누르고 WASD 또는 방향키로 이동합니다.
3. 다섯 갈림길마다 번호가 붙은 세 가지 분석 계획 중 하나로 걸어갑니다.
4. 길을 지난 뒤 선택 이유를 고릅니다.
5. 마지막 깃발에서 이동 경로와 선택 기록을 돌아봅니다.

추천 경로에서는 이동 속도가 빨라집니다. 추천과 다른 방향으로 걸으면 강아지가 멈춰 서거나 바닥에 누워 버텨 잠시 이동이 멎고, 이후에도 느리게 움직입니다. 게임에는 정답이나 점수가 없습니다.

## 기술

HTML, CSS, JavaScript, Canvas로 만든 정적 웹앱입니다. 한 판의 기록은 브라우저 메모리에만 남습니다.
